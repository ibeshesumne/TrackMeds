# TrackMeds

A medication tracking app for iOS. Log medications, track treatment countdowns, record symptoms and exercise, and export your data.

## Features

- Medication log with dosage and schedule
- Treatment countdown
- Daily records (doses, weight, exercise, symptoms)
- Export/import (JSON, CSV)
- Data stored locally on device
